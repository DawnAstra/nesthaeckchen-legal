## Datenlöschung

Die App speichert alle Daten ausschließlich lokal auf Ihrem Gerät —
auf unseren Servern werden keine personenbezogenen Daten gespeichert.

**So löschen Sie Ihre Daten vollständig:**

1. Öffnen Sie die App NestHäkchen
2. Gehen Sie zu **Einstellungen → Löschen**
3. Tippen Sie auf **„Alle Daten löschen"**
4. Bestätigen Sie mit Eingabe von „LOESCHEN"

Alternativ können Sie die App deinstallieren — alle Daten werden
dadurch entfernt.

Bei Fragen zur Datenlöschung wenden Sie sich an: app@mymatz.de
